## 复用决策：ADAPT

ID：`NRP-DEC-MMH-20261104-HOME`。协议版本：本机已安装的全网复用协议 3.2.0。
决策负责人：本次实现代理；最终视觉验收：品牌方。

| 方案 | 适用性与约束 | 结论 |
| --- | --- | --- |
| 适配现有静态 HTML、CSS、原生 JavaScript | 保留 GitHub Pages、现有资料和 URL，无新增运行依赖；可做渐进增强 | 采用 |
| 迁移到 React / Next.js 等框架 | 本轮首页需求不需要客户端路由或新后端，迁移增加维护和 SEO 验证范围 | 不采用 |

改变决策的主要依据：既有站点已有真实作品、门店资料、CMS 内容文件和联系路径；缺口集中在视觉层级与内容组织，无需更换技术栈。

## 内容与 SEO 保留

- 主打仪器野生眉私人定制，统一使用单仪器、双仪器。
- 保留十类项目：画派单仪器野生眉、画派双仪器初绒野生眉、手工野生眉、丝雾眉、绒雾眉、美瞳线、扩唇、改乌唇、纹发际线、纹人中窝。
- 所有项目一年内免费补色，不另加次数表述；未写具体价格，价格指向大众点评当期信息。
- 门店地址、电话、微信、营业时间、到店路线、2016 年从业及 2024 年 8 月开业等既有事实保留。
- 保留 canonical、中文和英文 hreflang、RSS、既有页面路径，以及首页全部既有锚点。
- 保留 LocalBusiness、Person、WebSite、WebPage、FAQPage、BreadcrumbList、VideoObject；未增加虚构评价或 AggregateRating。
- 删除原 WebSite 中指向 `/?q=` 的 SearchAction，因为现站没有对应的站内搜索功能。
- 新首页精选作品为静态策展；`content/home.json` 的主图设置继续生效；原作品页及其 CMS 数据读取方式不变。
- 子页面保留原版本。本轮没有把所有子页面一并换肤，也没有声称搜索收录、AI 推荐或预约转化已经提升。
