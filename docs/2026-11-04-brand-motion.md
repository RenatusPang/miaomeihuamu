本轮在 `codex/owner-cms-20261104` 的 `2d574b5` 上继续，只修改现有 `assets/brand-home.js`、`assets/brand-stage2.css`。不重做版式，不改作品与文案，不改 CMS 配置，不合并 main 或部署正式网站。

## 动效与边界

- 首页以真人作品揭示、标题、介绍、操作入口和图注构成一次错落出现。桌面图片最长 1100ms，手机 700ms；不改变图片色彩、清晰度或面部结构。
- 重点标题轻微上移，作品媒体做小幅裁切揭示，设计观察点与图注主要淡入。只观察指定内容节点，每个节点只播放一次，不逐段处理长文章，不添加滚动视差。
- 悬停图片缩放 1.018 倍，仅在支持悬停的精细指针上启用。手机滚动位移从 12px 减至 5px，时长降为 380ms。
- 保留原有作品分类 `details` 结构。短说明做 200–280ms 高度与透明度过渡；长图库只淡入淡出，避免数千像素的内容推动动画。
- 图片及预约弹窗保留原生 dialog、焦点管理、Escape 和背景关闭。关闭过渡 160ms，有计时器兜底。若原图片所在分类已关闭，焦点返回分类标题。
- 导航有细线状态反馈，按钮有轻微按下反馈，手机菜单支持快速反复开关。中英文使用同一组样式与行为。

所有正文保持静态 HTML。没有全局 `opacity: 0` 或等待脚本解锁的隐藏类；滚动动画通过原生 Web Animations API 临时施加，完成或取消后移除效果。禁用或阻断脚本时，手机导航直接展开，原生分类、图片链接和预约地址仍可使用。

系统减少动态效果时关闭 CSS、Web Animations、平滑滚动及悬停缩放，包括 dialog 的 `::backdrop`。设置在页面打开期间改变时，会取消正在运行的脚本动效。没有连续动画、第三方动画库、新字体、新接口或新增资源请求。

真实浏览器检查包括：

- 桌面 1440px、手机 390px：首页出现、滚动作品和设计理念、图片悬停、分类开合、图片放大与关闭、预约弹窗。
- 手机菜单连续快速开关、中英文切换、横向溢出和运行异常。
- 弹窗按钮及 Escape 关闭后的焦点返回；分类关闭过渡期间 Tab 不进入即将隐藏的内容。
- 分类关闭过程中改变 hash，目标分类仍保持展开，不被旧计时器关闭。
- 减少动态效果与阻断 `brand-home.js` 的降级路径。

测试发现并修复了分类关闭期间的焦点与 hash 竞争，以及减少动态效果遗漏 `::backdrop` 的问题。复验首页预约与作品放大弹窗时，CSS 动画事件、Web Animations 调用和当前运行动画均为 0。阻断脚本后移动导航、正文、原生分类及图片原链接正常。两种视口均无横向溢出或运行异常。完整结果见本地 `test-results.json`，其中 `initialReducedFailure` 保留修复前证据，其余 reduced 字段为最终复验。
