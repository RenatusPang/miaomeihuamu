描眉画目 · 维护说明后台入口

保存后，核对官网更新。

登录

Pages CMS 支持 GitHub 主账号登录，以及已授权邮箱的验证码登录。使用 Gmail 不需要提供 Google 密码；它是邮件验证码登录，并非 Google 授权按钮。账号及仓库授权由 Pages CMS 和 GitHub 管理，不写入网站源码。

目前只由店主管理线上内容。首次仓库连接或权限调整使用 GitHub 主账号；验证码、双重验证在官方页面完成。

作品图片与视频

  1. 进入对应作品分类，新增列表项。图片填写图片路径；视频填写 MP4/WebM 与封面。所有媒体用 CMS 上传选择器，不粘贴网盘分享链接。
  2. 填写中文标题、替代文字、作品说明；英文对应字段可独立修改。说明只写真实记录，不推断恢复时间或顾客体验。
  3. 打开“在网站展示”，保存。首页推荐再打开“首页与作品页精选”。精选序号数字越小越靠前；普通分类按列表拖动顺序展示。
  4. 毛流近照可打开“毛流细节区展示”。关闭“在网站展示”后，精选、细节、分类列表和搜索数据都会排除该条记录。
  5. 删除作品用列表项删除；更换图片只替换引用。要删除媒体文件，先确认首页、工作室及其他作品没有再引用它，否则生成检查会提示缺失文件。

上传图片会先单独保存到仓库，取消作品编辑不等于撤销已上传文件。测试结束需删除测试记录，再清理测试素材。

文字与双语

首页、乐乐与工作室、作品页介绍、设计依据、服务说明、常见问题和已有知识文章都在后台中编辑。每处中英文分别保存。保留现有服务网址标识、文章 slug、六项设计依据与六条常见问题；这些标识关联已有链接与排版。

首页封面可清空，清空后不会偷偷回退成旧图。大标题允许换行。服务价格仍以大众点评当期信息为准，所有项目一年内免费补色。

图片质量与视频限制

图片准备工具在设备内提供原图/处理图对比，默认最长边2560像素、WebP质量92，不放大、不磨皮。点击图片查看原始像素；细线变糊时提高质量或上传原图。

本站生成检查限图片20 MiB、视频24 MiB。GitHub单文件硬限制100 MiB，浏览器上传通常限25 MiB；这些不等于托管Pages CMS的请求上限，其实际最大值尚未确认。手机视频建议导出短片段、1080p、MP4/H.264。项目不使用Git LFS或付费视频服务。

查看保存与发布结果

Save 成功表示内容已写入仓库。main 的流程会生成中英文页面、校验，再发布同一版本的完整网站。后台入口显示正式官网已提供对应版本后，再检查实际页面。若失败，原成功版本会继续服务；先根据生成记录修正内容。

正式官网已启用自动发布。日常维护请选择 main 分支；保存后等待生成和发布成功，再打开官网检查。其他测试分支只生成预览，不会更新正式官网。

恢复历史内容

  1. 在Pages CMS的History查看提交，或从后台入口打开完整内容历史。记录要恢复的文件与旧版本。
  2. 使用GitHub主账号，打开该文件的旧提交，选择Raw并复制旧内容。随后回到当前测试或正式分支的同一文件，点Edit粘贴并另存为新提交。
  3. 整份作品JSON包含同一分类的所有记录。若旧版本之后还有其他更新，仅恢复需要的那条记录，避免覆盖后续作品。
  4. 如果旧图也被删除，从同一历史版本恢复图片文件，再恢复内容引用。等待生成与发布通过，再检查官网；测试分支则检查预览。

Pages CMS目前提供历史查看，没有原生“一键恢复”按钮。Git历史不会因普通删除消失；恢复不需要重置分支或强制推送。
